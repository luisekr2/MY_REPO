# Relationship Engine v0.1

This module adds a dyadic interaction graph on top of the existing Saju Required Function / Availability Graph.

## Outputs

- asymmetric A-to-B and B-to-A functional supply
- overload risk
- attraction
- communication
- conflict
- power balance
- autonomy
- stability
- growth complementarity
- practical fit
- romantic chemistry
- relationship confidence
- timing synchrony placeholder for v0.2

The model intentionally does not collapse the relationship into a single compatibility score.

## Local validation

The local v1.9 build passed TypeScript compilation plus relationship, availability, and structure regression checks before upload.
