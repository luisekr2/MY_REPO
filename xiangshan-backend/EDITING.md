# XiangShan Backend 문서 편집

각 Markdown 문서는 같은 이름의 HTML에서 변환한 편집용 사본입니다.

- 본문·제목·예제·표: 해당 .md 파일을 수정합니다.
- 그림: assets/문서이름/figure-NN.png를 사용합니다. 같은 위치의 .svg는 편집 가능한 벡터 원본입니다.
- 그림 변경: SVG를 편집한 뒤 같은 이름의 PNG도 다시 내보내야 Markdown에 반영됩니다.
- 이미지 경로는 상대 경로입니다. 다운로드하거나 이동할 때 assets 폴더도 함께 유지하세요.
- 목차·절 이동을 위해 남겨 둔 `<a id="…"></a>` 앵커는 유지하세요. 제목을 바꾸면 목차의 표시 문구도 수정하세요.
- Markdown 수정은 기존 HTML에 자동 반영되지 않습니다. HTML은 업로드 당시의 별도 사본으로 유지합니다.

PNG는 원래 문서에 표시된 그림을 2배 해상도로 저장했습니다. SVG에는 독립적으로 열 수 있도록 글꼴과 크기 속성을 보완했습니다.
