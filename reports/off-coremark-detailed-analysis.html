01 / Executive verdict

OFF 단일 실행은 유효하다

최종 실행은 difftest를 켠 상태로 GOOD TRAP과 exit 0에 도달했고, 압축 비활성화의 네 가지 카운터 불변식을 모두 만족했습니다.

따라서 이 실행은 “ROB 압축 OFF 구현의 기능 smoke test”로 채택할 수 있습니다. 단, 최종 표본은 1회이므로 ON 대비 성능 효과나 반복 분산을 말하는 실험 결과로는 아직 불충분합니다.

실패는 seed가 아니었다

파일 수정 시각과 로그 서명을 기준으로 재구성한 진단 이력입니다. 중간 로그는 성능 표본에서 제외합니다.

같은 실패 재현 — seed 1과 seed 0 모두 동일 PC, 동일 174 instructions, 동일 register delta. 무작위 seed 원인 가설을 배제.

2026-07-28 01:00 KST · rebuilt emulator

OFF 경로 보강 후 재빌드 완료 — fusion 비활성화, 최종 CompressUnit gate, rename의 numWB 계산 및 RF arbitration tie-break 수정이 dirty tree에 존재.

PASS — 663,688 instructions, GOOD TRAP, CRC 정상, OFF 카운터 0, exit 0.

07 / Interpretation boundaries

이 보고서가 말하지 않는 것

ON 대비 효과가 아닙니다.
이 문서는 OFF 단일 실행의 유효성 분석입니다. 동일 최종 코드·조건의 ON 표본과 직접 비교하지 않았습니다.
반복 통계가 없습니다.
계획된 3회가 아니라 최종 성공 1회뿐입니다. 평균, 표준편차, 신뢰구간, 유의성은 계산할 수 없습니다.
CoreMark 공식 점수 보고서가 아닙니다.
2 iterations의 smoke binary이며 시스템 포트·컴파일 플래그·공식 run rule 검증이 없습니다.
완전한 깨끗한 소스 상태가 아닙니다.
기준 commit은 고정됐지만 실행 로그가 dirty: 1을 명시합니다. 재현에는 기준 SHA뿐 아니라 현재 7개 파일의 patch 보존이 필요합니다.
